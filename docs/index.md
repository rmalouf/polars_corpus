# polars-corpus

polars-corpus is a Python/Rust extension for Polars that brings corpus linguistics workflows
into the DataFrame ecosystem. It is designed to handle large corpora (100M+ words) on
modest hardware without requiring external servers or databases.

## Examples:

  - [Word frequencies](notebooks/frequencies.ipynb)
  - [Keyword Analysis](notebooks/keywords.ipynb)
  - [Lexical Dispersion](notebooks/dispersion.ipynb)
